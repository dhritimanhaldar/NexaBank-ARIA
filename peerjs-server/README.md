# NexaBank PeerJS Signaling Server

Deploy this folder to Render as a Web Service.

## Render settings

- Root Directory: `peerjs-server`
- Environment: `Node`
- Build Command: `npm install`
- Start Command: `npm start`

## Environment Variables

- `PEERJS_KEY=NexaBank-ARIA-peerkey-secret`

## Public endpoint

- `https://nexabank-peerjs-server.onrender.com/peerjs`
